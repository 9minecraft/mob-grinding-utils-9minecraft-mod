# Mob Grinding Utils — Automate Mob Farms Without Redstone

Mob Grinding Utils 9minecraft Mod gives you all the tools needed to build automatic monster farms. This mod adds special blocks that spawn, move, and defeat mobs on their own. You can collect items and store experience points in large liquid tanks. It replaces messy water flows and complicated redstone traps with simple machines. Players can set up a complete farming system in a very small space.

Custom Mob Spawning: Hit a mob with a swab, put it in the spawner, and watch it clone that exact creature.

## What this build is

An unofficial rebuild of **vadis365**'s original work, kept running on current Minecraft releases by 9Minecraft Studios. Not affiliated with the original author and not endorsed by them.

Most of the porting work sits in the mixin layer. Each Minecraft release moves or renames the methods this mod hooks into, so the hooks are re-pointed and re-tested against that version rather than rewritten. The behaviour underneath is upstream's and is deliberately left alone — that is the part that makes the mod feel right, and it is not ours to redesign.
